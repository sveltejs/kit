# @sveltejs/adapter-server

Building blocks for SvelteKit [adapters](https://svelte.dev/docs/kit/adapters) that generate a standalone server, such as [`@sveltejs/adapter-node`](https://svelte.dev/docs/kit/adapter-node) and [`@sveltejs/adapter-bun`](https://svelte.dev/docs/kit/adapter-bun). It is not an adapter itself.

`@sveltejs/adapter-server` is imported by an adapter while it builds, and `@sveltejs/adapter-server/runtime` by the server the adapter generates.

## typescript_unsupported

> Could not load TypeScript %version%: %details%

SvelteKit uses TypeScript to generate the `./$types` of your route files and to validate your `tsconfig.json`. It supports TypeScript 6, and TypeScript 7.1 or later, but could not use the API of the version you have installed, so it continues as if TypeScript was not installed. Install a version of TypeScript that SvelteKit supports.
